# Security Policy

## Supported Versions

Only the latest minor release is actively supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

Do not report security vulnerabilities via public GitHub issues.
Submit reports securely through private vulnerability reporting on the GitHub repository or contact the core maintainers directly. Include reproduction steps, environment details, and proof-of-concept scripts.
