# Roadmap

## Current milestone

The repository currently contains the initial monorepo foundation and verification pipeline for Mahiva Codebase Mapping.

## Planned phases

1. Foundation and monorepo setup
2. Filesystem engine
3. Scanner and language registry
4. Parser and normalized AST
5. Symbol and import analysis
6. Semantic analysis and relationships
7. SQLite persistence and graph engine
8. Query engine and CLI
9. Git integration and incremental scans
10. Impact analysis, metrics, and analyzer packages
11. Fastify API and React web app
12. Visualization, security, and performance hardening
13. Release packaging and publishing

## Guiding principle

Mahiva should remain deterministic and evidence-driven. Static analysis comes first; AI support can be layered on afterward as an optional explanation layer.
