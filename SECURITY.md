# Security Policy

## Supported versions

This repository is currently in active development. Security fixes are handled on the main branch and will be backported when feasible.

## Reporting a vulnerability

Please do not open a public GitHub issue for security vulnerabilities.

Instead, report the issue privately by contacting the maintainers through the repository’s security contact channel or by opening a confidential report through GitHub’s security advisory workflow if available.

Please include:

- a concise description of the issue
- steps to reproduce it
- the affected version or commit
- any suggested mitigation or patch

## Response expectations

We aim to acknowledge and triage higher-risk reports promptly. Fixes will be prioritized based on severity and impact.
